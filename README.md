# Prince of Persia: Warrior Within — Nintendo Switch

An educational reverse-engineering and native porting research project
focused on the original Xbox version of Prince of Persia: Warrior Within.

## Project Goal

Investigate the original Xbox executable (XBE), understand its code and
dependencies, and explore the feasibility of bringing the game to Nintendo
Switch through a native port or static recompilation.

## Current Status

- [x] Extracted and indexed resources from the game's BF archive.
- [x] Conducted preliminary BF resource analysis.
- [x] Inspected the XBE header and section table.
- [ ] Decode and investigate the XBE entry point.
- [ ] Analyze imported Xbox kernel and library functions.
- [ ] Evaluate static recompilation feasibility.
- [ ] Develop the Nintendo Switch implementation.

## Repository Structure

- `docs/` — Research notes and technical documentation.
- `tools/` — Python scripts developed for analysis.
- `research/` — Analysis reports and findings.
- `source/` — Future port implementation.
- `tests/` — Tests and experiments.

## Important Notice

This repository does not contain the original game, executable files,
game assets, or copyrighted resources.

You must own a legitimate copy of the game to conduct your own research.
